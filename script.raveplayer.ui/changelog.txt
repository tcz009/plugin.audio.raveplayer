Rave Player 3.9.57 — cancel/data-integrity fix
- Cancelling a download can no longer delete a successfully completed file for
  another row that shares the same URL. Completed entries are deleted by job
  identity (key) only, never by URL.
- A queued-cancel sidecar is cleared on owner start and terminal load, so a
  later retry of the same key runs normally instead of being cancelled/deleted.
- The screen download queue now uses the lazy plugin modules hook for
  completed-file deletion, so a screen cancel removes its own file/index row.
- The owner persists a cancelled status inferred from the sidecar, so losing
  the sidecar cannot resurrect the row.

Rave Player 3.9.56 — remaining Kodi P2s (device QA + advisor)
- Downloads: its rows use the neutral screen bed; the FAVOURITES hero no
  longer appears when the Downloads room opens.
- Now playing: an external Player.Stop clears the stale app status line and
  the now-playing property via the 1 Hz player observation.
- Downloads cancel: duplicate rows for one URL are cancelled together; a
  completed copy under the same key is deleted; the plugin download overlay
  has a CANCEL button and Back/Stop cancel the transfer.
- Instance lock: an OS flock heals a stale same-PID marker immediately.
- Paint cache: read-time age check, 64 MiB byte cap/prune, and fail-soft
  encode/decode so malformed cache entries never abort a room.
- Page 2 refresh keeps focus off the nav row; clamped pages refresh with the
  painted page; cache keys carry a navigation token.
- Remove favourite / delete download invalidate the cached screen first.
- Prefetch stops on D-pad focus movement.
- Screen 3.9.56 requires plugin 3.9.56; resolver module stays 1.1.0. Code
  only: no device run, no push and no tag.

# Rave Player Screen 3.9.51 — performance pass

- **Stale-while-revalidate paint.** The last good page for each room/folder is
  stored under the add-on profile and painted immediately, then refreshed on a
  background thread; the list repaints only if the rows changed. A subtle
  `UPDATING · showing saved list` status is shown and Back is never blocked.
- **Lazy plugin imports.** `pluginbridge` now imports only `plugin.kodi` up
  front (needed to bind the plugin's add-on context) and loads every data
  module on first use. Home paints without importing Latest, Legacy, Toronto,
  radio, feeds or downloads.
- **Idle prefetch.** Once Home has painted and the user has not acted, a
  bounded, cancellable thread warms Latest and the RaveTapePacks index into the
  paint cache.
- **Instant Back.** The close path fires `ActivateWindow(Home)` once, waits up
  to 200 ms and retries once only if Kodi refused, instead of twelve 200 ms
  polls.

# Rave Player 3.9.47

- **New add-on `script.raveplayer.ui` ("Rave Screen")** — a proper full-screen
  Kodi `WindowXML` window, not an overlay stuck on top of a plugin directory.
  1280×720, 2026 sticker styling, big hero art, a vertical D-pad row list,
  OK/Back handling and skin `<animation>` focus transitions.
- **Spinning Surprise** — picks exactly one random tape pack and one track,
  spins the big Rave Player head for at least 1.2 seconds on the GUI thread
  (`xbmc.sleep` + `setImage`, letting Kodi repaint), then hands playback to
  Kodi with a one-item music playlist and shows
  “Now playing: track — pack”. There is no re-pick loop and no repeated
  playback: a second OK while playing is a no-op.
- **Data, read-only** — the screen imports `plugin.audio.raveplayer`'s existing
  `resources/lib` modules under a private alias and calls only public helpers.
  Home rows: Latest, Toronto Rave Mixtape Archive, JungleTapes.com,
  RaveTapePacks.com, Live Radio, Spinning Surprise.
- **Entry point** — `plugin.audio.raveplayer` root gains a leading
  **Rave Screen** row (`mode=screen`) that closes the plugin directory and runs
  `script.raveplayer.ui`. If the script add-on is not installed the row tells
  the user and the normal lists remain fully usable.
- **Kodi 19–22** — the script manifest requires `xbmc.python 3.0.0` (Kodi 19).
  Because it depends on the plugin, the combined pair currently installs on
  Kodi 20–22; see `docs/RAVE-SCREEN.md` for the exact dependency note and the
  untested-on-device risk list.
- **Tests** — 47 new offline tests cover window open/close, focus movement,
  source loading, single-pick surprise, ≥1.2 s animation timing, playback
  handoff, no replay, Back pop/exit and the plugin launcher. Stub-based; no
  Shield or network access.
- **Artifacts** — both zips are built by `scripts/build.sh` and listed in
  `repo/addons.xml` by `scripts/build-repo.sh`; the current version is 3.9.47.
  No push, tag or deploy.
