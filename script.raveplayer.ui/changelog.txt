- **Rave Screen visual parity** — `script-raveplayer-ui.xml` rebuilt to the
  design specialist's `docs/rave-screen` control map: 1280×720 screen bed and
  grain overlay, header mark/wordmark/baked subtitle, acid+magenta rules,
  clock and room count, 640×360 hero poster (shadow, fanart, scrim, 140 px
  sticker, RP sticker/code, frame, baked kicker), cyan/paper title twins,
  fact+code meta and plot, 48 px rows with focus plate/shadow/bar/icon
  shadow/twin/fact/chevron, and the 1152×64 footer with ON AIR, baked NOW
  PLAYING, real `Player.*` title/artist/time/duration, waveform, 3 px progress
  and OK/BACK keycaps. The list remains **control 50** with `defaultcontrol 50`
  and no `setFocusId`; only `font13`/`font12`/`font10` are used.
- **Row rendering** — `ListItem.Label2` now carries a short fact (newest,
  1990–2014, cassette, 1992–2004, live, random, genre, show, tape count,
  track duration, source), the RP code/index ride as `rp_code`/`rp_index`
  item properties, the hero binds to `ListItem.Art(fanart)`/`Icon`, and the
  footer shows the selected row when idle and `Player.*` while playing.
- **Spinning Surprise** — restyled to the full-window burst/ring/head/caption
  composition with the baked SURPRISE ME and SPINNING THE RACK labels, RP-02
  code line and B CANCEL affordance. Behaviour is unchanged: one bounded pick,
  one ≥1.2 s head spin, one playback handoff, Back/fail-fast guards intact.
- **Art** — the 59 design assets are bundled under
  `resources/art/rave-screen/` (plus the untouched Rave Player mark), and every
  texture reference is an absolute `special://home/addons/script.raveplayer.ui`
  path so the skin cannot shadow it.
- **Tests** — new offline checks parse the XML, assert control 50/defaultcontrol
  50/no setFocusId, resolve every referenced texture, verify 720p geometry and
  64/36 safe margins for live type, and assert the focus/hero bindings and the
  data facts. Full suite green (634 tests); no device run.

# Rave Player 3.9.47

- **New add-on `script.raveplayer.ui` ("Rave Screen")** — a proper full-screen
  Kodi `WindowXML` window, not an overlay stuck on top of a plugin directory.
  1280×720, 2026 sticker styling, big hero art, a vertical D-pad row list,
  OK/Back handling and skin `<animation>` focus transitions.
- **Spinning Surprise** — picks exactly one random tape pack and one track,
  spins the big Rave Player head for at least 1.2 seconds on the GUI thread
  (`xbmc.sleep` + `setImage`, letting Kodi repaint), then hands playback to
  Kodi with a one-item music playlist and shows
  “Now playing: track — pack”. There is no re-pick loop and no repeated
  playback: a second OK while playing is a no-op.
- **Data, read-only** — the screen imports `plugin.audio.raveplayer`'s existing
  `resources/lib` modules under a private alias and calls only public helpers.
  Home rows: Latest, Toronto Rave Mixtape Archive, JungleTapes.com,
  RaveTapePacks.com, Live Radio, Spinning Surprise.
- **Entry point** — `plugin.audio.raveplayer` root gains a leading
  **Rave Screen** row (`mode=screen`) that closes the plugin directory and runs
  `script.raveplayer.ui`. If the script add-on is not installed the row tells
  the user and the normal lists remain fully usable.
- **Kodi 19–22** — the script manifest requires `xbmc.python 3.0.0` (Kodi 19).
  Because it depends on the plugin, the combined pair currently installs on
  Kodi 20–22; see `docs/RAVE-SCREEN.md` for the exact dependency note and the
  untested-on-device risk list.
- **Tests** — 47 new offline tests cover window open/close, focus movement,
  source loading, single-pick surprise, ≥1.2 s animation timing, playback
  handoff, no replay, Back pop/exit and the plugin launcher. Stub-based; no
  Shield or network access.
- **Artifacts** — both zips are built by `scripts/build.sh` and listed in
  `repo/addons.xml` by `scripts/build-repo.sh`; the current version is 3.9.47.
  No push, tag or deploy.
