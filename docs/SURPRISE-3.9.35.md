# Surprise Me reveal — 3.9.35

The Kodi Surprise Me route now matches the web version's spin-then-land moment.

- Reuses the existing 10-frame 256px Rave Player head frames, scaled to a large
  400px image in the new `raveplayer-surprise.xml` overlay. No new head art.
- `resources/art/surprise-burst.jpg` is a 1280×720 radial burst in the 2026
  sticker palette (black ink / pink spot colour + sparse halftone dots),
  generated by `scripts/make-surprise-art.py`; it is the only new art asset.
- Caption **SURPRISE ME**, sub-caption **SPINNING THE RACK…**, optional code
  line (`RANDOM PACK` by default), and “Back to cancel”.
- The head animates at ~10 fps for at least **1.2 seconds**. The overlay closes
  in `finally` before `latest.random_pack()` / `archive_item()`, so it never
  covers the directory or player.
- Back/Stop sets the existing cancel flag, closes cleanly, skips the random
  pick and ends the folder.
- A new setting **Animate Surprise Me** (`surprise_animate`, default on)
  disables the reveal and picks instantly (today's behaviour). A window/asset
  failure is logged and swallowed; the random pick still happens.

## Lifecycle

```
surprise (root row)
  if surprise_animate:
      SurpriseReveal.show()     ← 1.2 s minimum, 10 fps
      finally: close()
      if cancelled: end directory; return
  pack = latest.random_pack()
  archive_item(pack)            ← unchanged
```
