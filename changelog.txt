Rave Player 3.4.1
- Code-quality pass: disk cache with TTL for feeds, Archive search/metadata,
  legacy HTML and DNBRADIO recordings (menus load from cache; ~5 network
  calls per load become 0 when warm).
- Fixed real bugs: Toronto Rave Mixtape URLs with "&amp;" 404'd, Atom feeds
  returned no episodes, null Archive fields and malformed numFound could
  crash a route, corrupt gzip and unknown charsets could raise, fractional
  iTunes durations were wildly wrong, radio station lists could crash.
- Offline test suite grown from 21 to 88 tests.

Rave Player 3.4.0
- Present-day coverage: Podcasts & Mixes section built on RSS feeds, which
  are the most durable source there is (Jungle Lab, The M-Path-E Test,
  Viper Classic Rave, Toro In The Mix, Bad ChemCast — 248 episodes between
  them, newest first).
- DNB Radio Archive: recent jungle and drum & bass shows from DNBRADIO.com,
  with stream URLs resolved on demand.
- Tape packs stay the backbone: the ravetapes collection, the genre
  collections and the legacy sites are all still there.

Rave Player 3.3.1

Rave Player 3.2.0
- Added RaveTapePacks.com as a legacy source: one of the few fan sites from
  2014 still serving full tape packs. Its MP3s are hotlink-protected, so the
  add-on appends a Referer header via Kodi's URL syntax (403 without it,
  206 audio/mpeg with it — verified).

Rave Player 3.0.2
- Switched the archive sections to the curated Internet Archive collection
  "ravetapes" instead of keyword guessing: 724 real 1990s rave cassettes,
  with genre sections that stay on-genre (jungle/DnB 74, hardcore 86,
  house/garage 299, Kool FM/Centreforce/Don FM 14).
- Live radio tags corrected: "pirate" was a Dutch schlager tag and
  "oldschool" was hip-hop, so both were dropped; breakbeat added.
- Section names now match what they contain (Jungle / Drum & Bass,
  All Tape Packs).

Rave Player 3.0.1
- Tuned every Archive query against live result counts so no section comes
  back empty: jungle, hardcore, house/garage, pirate radio and drum & bass
  now all return real tape packs (the first pass used phrases the Archive
  barely indexes).
- Pirate Radio Archive now searches titles, which surfaces airchecks rather
  than unrelated shortwave recordings.

Rave Player 3.0.0 — 2026 rebuild
- Rebuilt for Kodi 21/22 on Python 3. The 2014 code was Python 2 and could not
  run on any current Kodi.
- Removed the dead dependencies: script.module.TheYid.common, urlresolver,
  script.module.simplejson and the bundled HTMLParser/urllib2 imports.
  The add-on now needs nothing beyond Kodi itself.
- Replaced 70 hand-written site scrapers with two maintained sources:
  the Internet Archive for tape packs and sets, and radio-browser.info for
  live stations. Dead fan sites can no longer break the whole add-on.
- New sections: Rave Tape Packs, Jungle, Hardcore, House & Garage,
  Pirate Radio Archive, Drum & Bass Sets, and live radio by genre.
- Archive search built in, with pagination and proper per-tape labels
  ("TAPE 3 - MASTERVIBE" rather than nine identical rows).
- Artwork and metadata on every item: Archive thumbnails, station logos,
  fanart, plot, genre and duration.
- Graceful failure: a dead source shows a notification and leaves the rest
  of the add-on usable.
- Settings for results per page and station limit.
